# amoobridge 组织默认文档

这个仓库不存放代码。里面的文件是组织下所有仓库的默认配置，GitHub 会自动继承。

| 文件 | 作用 |
|---|---|
| `CONTRIBUTING.md` | 贡献方式和提 PR 的要求 |
| `SECURITY.md` | 漏洞上报渠道 |
| `.github/PULL_REQUEST_TEMPLATE.md` | PR 模板 |
| `.github/ISSUE_TEMPLATE/` | issue 表单 |

项目仓库如果自己定义了同名文件，以项目仓库的为准。想覆盖某个模板，在项目仓库里放一份同名文件即可，不用改这里。

改动这里的文件会影响组织下所有项目，请走 PR。
